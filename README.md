# Calculatrice d’intérêt simple

## Description
Ce projet est une calculatrice d’intérêt simple.  
Elle permet de calculer l’intérêt gagné sur un capital selon un taux et une durée.

## Formule utilisée
Intérêt = (Capital × Taux × Temps) / 100

## Exemple
Capital : 1000  
Taux : 5%  
Temps : 2 ans  

Intérêt = (1000 × 5 × 2) / 100 = 100
